# EdNet 데이터 사전

작성일: 2026-10-08 / 수정일: 2026-10-15
출처: [EdNet 공식 저장소](https://github.com/riiid/ednet), [데이터 논문](https://arxiv.org/abs/1912.03072)
이용 조건: CC BY-NC 4.0 (비상업적 연구 목적, 출처 표시)

EdNet은 토익 학습 서비스 산타(Santa)가 수집한 학생의 학습 기록이다. KT1부터 KT4까지 네 단계로 제공되며, 단계가 올라갈수록 앞 단계를 포함하면서 기록하는 행동이 늘어난다. 원본은 학생 한 명당 CSV 파일 하나로 나뉘어 있고, 이 프로젝트에서는 단계별로 DuckDB 테이블 하나로 합쳐 쓴다.

| 단계 | 담긴 내용 | 학생 수 | 기간 (UTC) | 이 프로젝트에서 |
|---|---|---|---|---|
| KT1 | 문제 풀이 기록 (문제당 한 줄) | 784,309 | 2017-04-18 ~ 2019-12-02 | 검증 중단, 대조용 |
| KT2 | 문제 푸는 과정의 행동 | 297,444 (문서) | 2018-08-27 ~ (문서) | 쓰지 않음 |
| KT3 | KT2 + 해설 읽기, 강의 시청 | 297,915 (문서) | 2018-08-27 ~ (문서) | 쓰지 않음 |
| KT4 | KT3 + 선택지 지우기, 음성·영상, 결제, 쿠폰 | 297,915 | 2018-08-27 ~ 2019-12-01 | **분석 기준** |
| Contents | 문제, 강의, 결제 상품, 쿠폰 정보 | | | 연결용 |

"(문서)"는 공식 문서 수치이고, 나머지는 실제 데이터로 확인했다.

## 1. KT1에서 시작했다

가장 단순한 KT1부터 테이블로 합쳐 검증을 시작했다. (`notebooks/03_kt1_pre_processing`)

### 한 줄의 뜻

학생 한 명이 문제 하나에 답한 기록.

### 컬럼

| 컬럼 | 뜻 | 형식 |
|---|---|---|
| `user_id` | 학생 번호. 원본에는 없고 파일 이름에서 뽑아 붙임 | `u{정수}` |
| `timestamp` | 문제가 제시된 시각 | 유닉스 시각, 밀리초 |
| `solving_id` | 그 학생이 문제 묶음을 푼 순번. 학생마다 1부터 시작 | 정수 |
| `question_id` | 문제 ID | `q{정수}` |
| `user_answer` | 제출한 답 | `a`~`d` |
| `elapsed_time` | 문제를 푸는 데 걸린 시간. 정확한 정의는 미확인 | 밀리초 |

### 검증한 것

| 컬럼 | 공식 문서와 일치 | 공식 문서와 다름 | 그 밖에 발견한 것 |
|---|---|---|---|
| `user_id` | 학생 784,309명 = 파일 784,309개 | 없음 | 빈 값, 형식 오류 없음 |
| `timestamp` | 가장 이른 날짜 2017-04-18 = 수집 시작일 | 없음 | 13자리 밀리초. 2017-04-18 ~ 2019-12-02 |
| 컬럼 구성 | 본문 설명의 5개 컬럼 | 예시 표 머리글이 `question_id`, `bundle_id`로 잘못 적힘. 실제는 `solving_id`, `question_id` | |

중복도 확인했다. 학생·시각·문제가 같은 기록이 3,452묶음(학생 803명) 있다. 학생·`solving_id`·문제는 같은데 시각이 다른 675,805묶음은 오류인지 판단할 수 없어 보류했다.

## 2. KT2, KT3

KT4에 모두 포함되어 있어 분석에 쓰지 않는다. 컬럼은 KT4에서 `cursor_time`을 뺀 것과 같다. (`notebooks/02_build_tables`에서 확인)


### KT4로 넘어간 이유

이 프로젝트의 질문은 **"공부를 잘하는 사람과 못하는 사람은 행동 패턴이 어떻게 다를까?"**다.

KT1을 검증하면서 KT1에는 **무엇을 답했고 얼마나 걸렸는지**만 있다는 것을 확인했다. 해설을 읽었는지, 강의를 봤는지, 답을 고쳤는지, 어느 경로에서 풀었는지 같은 행동은 기록되어 있지 않다. 그래서 KT1로는 질문에 답할 수 없다고 판단하고, **KT1 검증을 중단한 뒤 행동 전체가 담긴 KT4로 넘어갔다.**

## 3. KT4를 분석 기준으로 삼았다

KT4는 KT3를 모두 포함하고, KT3는 KT2를 포함한다. 공식 문서에 따르면 KT1의 정보도 KT2로 복원할 수 있다. 그래서 KT2와 KT3를 따로 검증하지 않고 KT4 하나를 기준으로 삼았다. (`notebooks/04_kt4_pre_processing`)

대신 KT4는 2018-08-27 이후 기록만 있어서, 분석 대상이 78만 명에서 약 30만 명으로 줄어든다.

### 한 줄의 뜻

학생이 산타 화면에서 한 행동 하나. 전체 131,441,538행.

### 컬럼

| 컬럼 | 뜻 | 형식 | 검증 |
|---|---|---|---|
| `user_id` | 학생 번호. 원본에는 없고 파일 이름에서 뽑아 붙임 | `u{정수}` | 완료 |
| `timestamp` | 행동한 시각 | 유닉스 시각, 밀리초 | 완료 |
| `action_type` | 행동의 종류 | 아래 13개 값 | 완료 |
| `item_id` | 행동의 대상 | 접두어 + 정수 (아래 표) | 완료 |
| `cursor_time` | 음성·영상을 재생하거나 멈춘 지점 | 정수 | 미완료 |
| `source` | 행동한 경로 | 아래 값 (문서 기준) | 미완료 |
| `user_answer` | 고른 답 또는 지운 선택지 | `a`~`d` | 미완료 |
| `platform` | 접속 환경 | `mobile`, `web` | 미완료 |

### action_type과 item_id

| action_type | 뜻 | item_id 접두어 (실제 데이터) |

| `enter` | 문제 묶음, 해설, 강의 화면에 들어감 | `b`, `e`, `l` |
| `respond` | 문제 하나에 답을 고름. 같은 문제에 여러 번 가능하고 제출 직전의 마지막 답이 최종 답 | `q` |
| `submit` | 묶음의 최종 답을 제출 | `b` |
| `quit` | 해설, 강의 화면에서 나옴 | `e`, `l` |
| `erase_choice` | 선택지를 지움 | `q` |
| `undo_erase_choice` | 지운 선택지를 되돌림 | `q` |
| `play_audio`, `pause_audio` | 음성 재생, 일시정지 | `b` |
| `play_video`, `pause_video` | 영상 재생, 일시정지 | `l` (일부 `-1`) |
| `pay` | 결제 | `p` |
| `refund` | 환불 | `p` |
| `enroll_coupon` | 쿠폰 입력 | `c` |

### 컬럼별 검증 결과

#### `user_id`

**공식 문서와 일치**
- 학생 297,915명 = KT4 파일 297,915개
- 전체 131,441,538행 = 문서의 상호작용 131,441,538건
- 학생당 평균 441.20행 = 문서의 평균 441.20건

**공식 문서와 다름**
- 문서 개요는 "784,309명에게서 131,441,538건, 학생당 평균 441.20건"이라고 한 문장에 적었다. 그러나 131,441,538 ÷ 784,309 = 약 167.6이다. 131,441,538건과 441.20은 KT4(297,915명) 기준 수치이고, 784,309명은 KT1 기준이다.

**그 밖에 발견한 것**
- 빈 값, 형식 오류 없음
- 학생별 행 수는 최솟값 2, 중앙값 31, 75% 95, 최댓값 203,338, 평균 약 441. 평균이 75% 값보다 커서 소수의 학생이 기록 대부분을 차지한다. 분석은 학생 단위로 한다.

#### `timestamp`

**공식 문서와 일치**
- 가장 이른 날짜 2018-08-27 = KT2~KT4 수집 시작일

**공식 문서와 다름**
- 없음. 다만 문서는 시각을 보안 문제로 옮겼다고 하는데, 가장 이른 날짜가 문서의 수집 시작일과 같다. 이 둘이 어떻게 맞는지는 확인하지 못했다.

**그 밖에 발견한 것**
- 빈 값, 형식 오류 없음. 모두 13자리 밀리초
- 2018-08-27 ~ 2019-12-01, 462일 모두 기록이 있다.
- 마지막 5일은 기록이 거의 없다. 2019-11-27에 63,696행으로 줄고, 11-28~12-01은 하루 24~68행이다. 분석 기간에 넣을지는 분석 질문을 정한 뒤 결정한다.
- UTC에 9시간을 더하면 행 수가 새벽 5시에 가장 적고 밤 10시에 가장 많다. 이를 근거로 **한국 시각으로 가정**한다.

#### `action_type`

**공식 문서와 일치**
- 본문의 13개 값이 모두 있고, 그 밖의 값은 없다.

**공식 문서와 다름**
- 예시 표의 `eliminate_choice`는 없다. 선택지 지우기는 본문대로 `erase_choice`로 기록되어 있다.
- 예시 표의 `text_enter`는 없다.

**그 밖에 발견한 것**
- 빈 값, 표기 오류 없음
- `enter`(32,943,087) = `submit`(16,488,061) + `quit`(16,455,026). 전체 합계로는 화면에 들어간 수와 나온 수가 맞는다. 각 `enter`에 짝이 있는지는 행끼리 비교해야 확인할 수 있다.
- 가장 많은 행동은 `enter`(25.06%)이고, `pay`(26,583행), `refund`(1,126행), `enroll_coupon`(603행)은 매우 드물다.

#### `item_id`

**공식 문서와 일치**
- 접두어 6개(`b`, `q`, `e`, `l`, `p`, `c`)와 `접두어{정수}` 형식
- 문서에 적힌 행동별 대상: `enter`는 묶음·해설·강의, `submit`은 묶음, `quit`은 해설·강의, `respond`는 문제, `enroll_coupon`은 쿠폰. 위반 0행

**공식 문서와 다름**
- 음성 행동(`play_audio`, `pause_audio`)은 예시 표에서 문제(`q`)와 해설(`e`)에 기록되어 있지만, 실제로는 모두 묶음(`b`)이다.
- `-1`이 722행 있다. 문서에는 `item_id`가 `-1`인 경우에 대한 설명이 없고, `-1`은 Contents 표에만 쓰인다.

**그 밖에 발견한 것**
- 문서에 설명이 없던 행동의 대상: `erase_choice`·`undo_erase_choice`는 문제(`q`), 영상은 강의(`l`), `refund`는 결제 상품(`p`)
- 접두어별 행 수가 행동별 행 수와 정확히 맞는다. `q` = `respond` + `erase_choice` + `undo_erase_choice`, `p` = `pay` + `refund`, `c` = `enroll_coupon`. `b`로 시작하는 `enter` 수(16,488,061)는 `submit` 수와 같다.
- KT4에 나온 서로 다른 문제는 11,555개, 강의는 971개다. 문서의 전체 문제 13,169개, 강의 1,021개 중 KT4에서 쓰인 것이다.
- `-1` 722행은 `play_video` 365행, `pause_video` 357행이다. 원인을 찾으려고 세 가설을 확인했지만 모두 설명하지 못했다.

| 가설 | 결과 | 판단 |
|---|---|---|
| 일부 학생에게만 몰려 있다 | 학생 65명 | 한두 명의 문제가 아님 |
| `sprint`에서만 생긴다 | 722행 중 344행(약 48%) | `sprint` 밖에서도 생김 |
| 특정 날짜에 몰려 있다 | 2018-10-19~2019-11-22 중 68일 | 특정 날짜의 장애로 보기 어려움 |

#### `cursor_time`, `source`, `user_answer`, `platform`

아직 검증하지 않았다. 참고로 `source`의 `diagnosis`는 문서의 경로 목록에 없지만, 학생 5명의 실제 파일과 KT4 테이블에서 학생 기록의 맨 앞에 나오는 것을 확인했다.

## 4. Contents (공식 문서 기준, 미검증)

**문제 (questions)**

| 컬럼 | 뜻 |
|---|---|
| `question_id` | 문제 ID (`q…`) |
| `bundle_id` | 문제가 속한 묶음 ID (`b…`). 묶음 하나에 문제 1~5개 |
| `explanation_id` | 해설 ID (`e…`). 번호는 묶음 ID와 같음 |
| `correct_answer` | 정답 (`a`~`d`). 파트 2는 보기 3개, 나머지는 4개 |
| `part` | 토익 파트 (1~7) |
| `tags` | 태그 목록 (`{정수};{정수};…`) |
| `deployed_at` | 제공되기 시작한 시각 (밀리초) |

**강의 (lectures)**

| 컬럼 | 뜻 |
|---|---|
| `lecture_id` | 강의 ID (`l…`) |
| `part` | 파트 (0~7). 0은 파트 없음 |
| `tags` | 태그 하나 |
| `video_length` | 영상 길이 (밀리초) |
| `deployed_at` | 제공되기 시작한 시각 (밀리초) |

강의 표의 `tags`, `video_length`, `deployed_at`은 값이 없으면 `-1`이다.

**결제 상품 (payment items)**

| 컬럼 | 뜻 |
|---|---|
| `payment_item_id` | 결제 상품 ID (`p…`) |
| `payment_type` | `pass`(기간제) 또는 `paygo`(수량제) |
| `duration` | `pass`의 이용 기간 (밀리초). `paygo`이면 `-1` |
| `number_of_questions` | `paygo`로 풀 수 있는 수. `pass`이면 `-1` |

**쿠폰 (coupons)**

| 컬럼 | 뜻 |
|---|---|
| `coupon_id` | 쿠폰 ID (`c…`) |
| `coupon_type` | 쿠폰 종류 (`type-{정수}`) |
| `duration` | 이용 기간 (밀리초) |

실제 토익 점수(scores)는 공개되지 않았다.
